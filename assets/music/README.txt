Three folders:
  menu/   songs for the menus and the lobby
  game/   songs for the games (Battle Royale: only with its Music option On)
  intro/  songs for the opening splash (one picked at random)
Each folder is shuffled on its own. Songs left loose in this folder play in both menu and game.
On Netlify / GitHub Pages run  node tools/make-playlist.js  before uploading.
